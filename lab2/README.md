# Лабораторная работа № 2. Страница «Собрать ланч»

## 📋 Описание проекта

Вторая лабораторная работа — страница меню для сайта доставки бизнес-ланчей **«Food Construct»**. На странице пользователь может выбрать суп, главное блюдо и напиток из предложенных вариантов.

Цель работы — закрепить навыки:
- создания семантической HTML-разметки;
- построения сеток на **CSS Grid** и **Flexbox**;
- стилизации интерактивных карточек с hover-эффектами;
- адаптивной вёрстки под планшеты и мобильные устройства;
- организации перекрёстной навигации между страницами сайта.

## 🛠️ Используемые технологии

- **HTML5** — семантическая разметка (`header`, `main`, `section`, `footer`, `nav`, `button`)
- **CSS3**:
  - **CSS Grid** — сетка блюд (3 колонки)
  - **Flexbox** — вертикальная раскладка внутри карточек и меню навигации
  - **Media Queries** — адаптивность (≤800px, ≤600px)
  - `filter: drop-shadow()` — тень карточек
  - `transition`, `:hover` — интерактивность
- **Google Fonts** — шрифт Montserrat (400, 500, 700)
- **CSS-переменные** (опционально) — для повторяющихся цветов

## 📝 Форма заказа (Лабораторная работа № 3)

Внизу страницы, после блока с меню (`<main>`), расположена **форма оформления заказа**. Форма отправляет данные методом **POST** на сервис [https://httpbin.org/post](https://httpbin.org/post), где отображаются все отправленные значения.

### 📐 Расположение

Форма находится **внутри страницы `lab2.html`** (в соответствии с требованиями задания), после блока `<main>` и перед `<footer>`.

### 🧩 Структура формы

Форма разделена на **2 блока** (`<fieldset>`), расположенных в 2 колонки (CSS Grid):

#### Блок 1 — «Ваш заказ»

| Элемент | Тип | Особенности |
|---------|-----|-------------|
| Суп | `<select>` | Опция по умолчанию с `value=""`, необязательный |
| Главное блюдо | `<select>` | Опция по умолчанию с `value=""`, необязательный |
| Напиток | `<select>` | Опция по умолчанию с `value=""`, необязательный |
| Комментарий к заказу | `<textarea>` | Многострочное поле, необязательное |

**Особенности селектов:**
- Первая опция: `value=""` (например, «Выберите суп»)
- Остальные опции имеют `value` на английском языке: `pho-bo`, `com-tam`, `vietnamese-coffee` и т.д.
- **Необязательные** — можно выбрать только 1 мясной/основной раздел, или 2, или все 3

#### Блок 2 — «Данные клиента»

| Элемент | Тип | Особенности |
|---------|-----|-------------|
| Имя | `input[type="text"]` | Обязательное (`required`) |
| Email | `input[type="email"]` | Обязательное (`required`) |
| Подписка на рассылку | `input[type="checkbox"]` | По умолчанию выбрана (`checked`) |
| Телефон | `input[type="tel"]` | Обязательное (`required`) |
| Адрес доставки | `input[type="text"]` | Обязательное (`required`) |
| Время доставки | `input[type="radio"]` | Обязательное (`required`), `fieldset` + `legend` |
| Точное время | `input[type="time"]` | `min="07:00"`, `max="23:00"`, `step="300"` (5 минут) |
| Сбросить | `button[type="reset"]` | Полностью очищает форму |
| Отправить | `button[type="submit"]` | Отправляет форму |

### ⚙️ Технические характеристики

- **Метод отправки:** POST
- **Адрес:** https://httpbin.org/post
- **Кодировка:** `application/x-www-form-urlencoded` (по умолчанию)
- **Валидация:** все обязательные поля защищены атрибутом `required`
- **Доступность:** все `<label>` связаны с соответствующими полями через `for` ↔ `id`
