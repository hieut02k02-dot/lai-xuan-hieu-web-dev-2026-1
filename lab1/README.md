# Лабораторная работа № 1. Вёрстка главной страницы сайта

## 📋 Описание проекта

Данная лабораторная работа представляет собой создание главной страницы сайта для доставки вьетнамской еды «Вкус Вьетнама». Цель работы — закрепить навыки вёрстки с использованием HTML и CSS, включая подключение шрифтов, создание семантической структуры и стилизацию элементов.

## 🚀 Демонстрация

Сайт доступен по ссылке: [Вкус Вьетнама — Вьетнамская кухня в Москве](https://lab1-lyong-web-dev-2026-1.vercel.app/)

## 🛠️ Используемые технологии

- HTML5 — семантическая разметка страницы
- CSS3 — стилизация и адаптивный дизайн
- Google Fonts — подключение шрифта Montserrat
- Flexbox — построение гибких макетов
- Media Queries — адаптивность под разные устройства

## 📄 Структура страницы

### Шапка сайта (`<header>`)

- Заголовок с названием сайта (`<h1>`)
- Навигационное меню (`<nav>`) с ссылками:
  - О нас
  - Преимущества
  - Меню
  - Контакты (якорная ссылка на футер)

### Основное содержимое (`<main>`)

**1. Блок «О нас» (`<section>`)**

- Заголовок (`<h2>`)
- Изображение (`<img>`)
- Текстовое описание компании (`<p>`)

**2. Блок «Преимущества» (`<section>`)**

- Заголовок (`<h2>`)
- Маркированный список (`<ul>`) с 4 преимуществами

**3. Блок «Топ-5 популярных блюд» (`<section>`)**

- Заголовок (`<h2>`)
- Таблица (`<table>`) с информацией о блюдах:
  - № п/п
  - Фото блюда
  - Название
  - Количество заказов в неделю
  - Цена

### Футер (`<footer>`)

- Контактная информация:
  - Номер телефона (кликабельный)
  - Email (кликабельный)
- Тёмный фон с белым текстом

## 🎨 Особенности дизайна

### Шрифты

- Подключен шрифт Montserrat из Google Fonts
- Поддерживает кириллицу и латиницу
- Используемые начертания: 400, 500, 700

### Цветовая схема

- Основной текст: `#111111`, `#222222`
- Акцентный цвет: `#d94b32` (красный)
- Фон: `#ffffff`, `#f5f5f5`
- Футер: чёрный фон (`#000000`) с белым текстом

### Изображения

- Все изображения имеют скруглённые углы
- Изображения блюд в таблице имеют соотношение 16:9
- Использование `object-fit: cover` для заполнения области изображения
- Эффект масштабирования при наведении (`hover`)

### Адаптивность

- Ширина контента: 70% на десктопе
- Плавное изменение ширины на планшетах (85%) и мобильных устройствах (92%)
- Уменьшение размера изображений на маленьких экранах
- Гибкое навигационное меню с переносом элементов

## 📱 Адаптивность

### Десктоп (ширина > 950px)

- Контент занимает 70% ширины экрана
- Изображение основного блока занимает 60% ширины контента
- Изображения блюд: 100×80px
- Размер основного текста: 14px
- Заголовок `h1`: 24px
- Заголовки `h2`: 18px

### Планшет (до 950px)

- Контент занимает 85% ширины экрана
- Сохраняется гибкая структура страницы
- Навигационное меню адаптируется под ширину экрана

### Мобильные устройства (до 600px)

- Контент занимает 92% ширины экрана
- Заголовок `h1`: 22px
- Заголовок `h2`: 17px
- Основное изображение занимает 100% ширины
- Навигация поддерживает перенос элементов (`flex-wrap`)
- Размер таблицы и отступов уменьшается
- Изображения блюд уменьшаются до 70×60px
- Размер текста футера уменьшается
